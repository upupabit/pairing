Active engine

Which engine below actually answers chat and embedding requests. Ollama and Matricxon can each be configured and started independently of this choice — switching here doesn't stop or start either one, it only changes where new requests go.

Ollama and Matricxon each keep their own separate model storage — nothing pulled under one is automatically available under the other. A conversation whose model isn't installed on the engine you're switching to will fall back to another installed model automatically, but you may still need to pull models again below for anything you specifically want available here.
