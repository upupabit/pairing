Update nodes

Updates Matricxon from GitHub on every node, one at a time, and restarts each. In a cluster the next node starts only when the last one is back with a quorum, and the leader goes last, so the cluster keeps serving. It stops at the first error. A node must be a git checkout; one in a container is skipped.
