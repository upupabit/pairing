This server

Saved into this server's own .env and used after a restart. Every server has its own, so do the same on each of them (a load balancer decides which one you are on).

Existing files are not moved. Copy the current folders' contents into the new ones before restarting, or chats lose their attachments and pictures.

The current key is never shown. To share one key: generate it here, copy it, and paste the same key on every other server. Changing it logs everyone out once.
