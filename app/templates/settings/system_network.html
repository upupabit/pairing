Outbound HTTP proxy

Is used to download models from this UI as well as external servers if you configure them to run locally. Unrelated to "Local {{ app_name }} server mode" above, which is about requests to this app, not requests from it. Username/password are optional — no scheme picker, always built as http://[user[:pass]@]host:port.

RAG (Knowledge base)

Applies to every user's own document uploads (Settings > Knowledge). The per-file limit also applies to shared/global uploads; the storage quota doesn't.

, the active engine, has no embedding models, so the knowledge base can't be used while it is active, even with RAG enabled. Switch to an engine with embeddings to use it.

Enable RAG (Knowledge base) for users

Off disables uploading/deleting documents on the Knowledge tab for every user and stops chats from searching it — affects every inference engine the same way, regardless of whether it could technically support embeddings. Remember to press Save below.

Default models

The models the system uses by default: for a new account's chats, for messages with an image, and for the Knowledge base (RAG). Each has its own Save button.

Default model for new users

Whichever model is picked here is what a brand-new account is created with.

No models installed yet — install one above before adding new users.

Default vision model

Any message with an image attached is answered by this model for that one reply only — a conversation's own model is never changed by this.

, the active engine, doesn't support images: messages are sent as text only, so this setting has no effect until you switch to llama.cpp or Matricxon.

No vision-capable models installed yet — pull one (e.g. llava) above to enable image attachments.

Default embedding model

Powers the Knowledge base (RAG) feature for every user — never used for chat. Switching this after documents were already ingested with a different embedding model doesn't re-embed them; their existing vectors stay as they are.

No embedding models installed yet — pull one above to enable the Knowledge base (RAG) feature.
