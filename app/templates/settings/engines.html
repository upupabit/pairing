Active engine

Which engine below actually answers chat and embedding requests. llama.cpp and Matricxon can each be configured and started independently of this choice — switching here doesn't stop or start either one, it only changes where new requests go.

llama.cpp and Matricxon share one models folder when both run locally with their default folders, so a model pulled under one is installed for both. Not every model runs on both engines, and a remote server has its own models. A conversation whose model isn't available on the engine you're switching to falls back to another installed model automatically.
