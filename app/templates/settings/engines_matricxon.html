Matricxon

A from-scratch inference server, Ollama-API-compatible local runtime. Local mode lets this app manage important tuning and start/stop Matricxon from here — Matricxon has no standalone binary, just a project checkout; Remote mode points at server/s running elsewhere using internal load balancer.

Local: this app starts, stops and configures Matricxon. Remote: it only talks to the nodes and never starts, stops or configures them. In a cluster, switch to Remote once the first node should be like the others; no node is lost by switching.
