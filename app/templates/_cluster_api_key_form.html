API key

Protects what the nodes serve: with a key, a node answers chats, embeddings and reranking only for callers that send it, so other programs on the network can't use your models. pAIring sends it on every call. The admin secret above protects the admin actions; this protects the models.

  • Every node gets it at once, with no restart. All nodes must answer; if one doesn't, nothing changes.
  • A node you add later gets it while it is set up.
  • Other programs that call the nodes (an OpenAI SDK, for example) need the same key. pAIring never shows it again: copy it before you save.
